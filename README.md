# MEBmebis - 方块像素图片屏插件

一个 PocketMine-MP 5.x 插件，使用彩色方块自动构建像素图片屏，将图片转换为游戏内的方块。

## ✨ 特性

- ✅ 使用彩色混凝土、羊毛等方块构建静态图片（PNG/JPG）
- ✅ **一键生成**：站在原地输入命令，自动在前方生成方块
- ✅ 使用 50+ 种方块智能匹配颜色
- ✅ 自由尺寸，每个方块 = 1 像素
- ✅ 支持四个方向（东南西北）

## 📦 安装

1. 将插件放入 `plugins` 目录
2. 重启服务器
3. 将图片文件放入 `plugin_data/MEBImgScreen/images/` 目录

## 🚀 快速开始

### 最简单的方式（推荐）

```bash
# 1. 将图片放入 plugin_data/MEBImgScreen/images/
# 2. 站在你想要的位置，面向图片应该朝向的方向
# 3. 输入命令

/mebis make 你的图片.png

# 就这样！插件会自动创建 16×16 的方块像素画
```

### 指定尺寸

```bash
# 创建 32×32 的大屏
/mebis make banner.png 32 32

# 创建 48×24 的横幅
/mebis make wide.png 48 24
```

## 🎮 命令列表

| 命令 | 说明 | 示例 |
|------|------|------|
| `/mebis make <图片名> [宽] [高]` | 快速创建（默认16×16） | `/mebis make logo.png 32 32` |
| `/mebis create <ID> <宽> <高> <方向> <图片名>` | 完整创建 | `/mebis create ad1 48 48 north banner.png` |
| `/mebis list` | 列出所有图片屏 | - |
| `/mebis info <ID>` | 查看详细信息 | `/mebis info ad1` |
| `/mebis remove <ID>` | 删除图片屏 | `/mebis remove ad1` |
| `/mebis reload` | 重载配置 | - |

## ⚙️ 配置文件

`plugin_data/MEBImgScreen/config.yml`:

```yaml
版本: 1.0.0
最大屏幕数: 50
```

## 🎨 尺寸参考

| 尺寸 | 方块数量 | 适用场景 |
|------|----------|---------|
| 16×16 | 256 方块 | 小型 |
| 32×32 | 1024 方块 | 标准 |
| 48×48 | 2304 方块 | 大型 |
| 64×64 | 4096 方块 | 超大 |
| 128×128 | 16384 方块 | - |

**注意**：尺寸越大，放置方块耗时越长。

## ⚡ 图片优化建议

**图片准备：**
- 调整到目标尺寸（16×16 到 64×64 像素）
- 使用简单明快的颜色和清晰的图案
- 压缩文件大小（推荐 < 1MB）
